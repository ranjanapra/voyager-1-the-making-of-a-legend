Directory: VY1PLA_DIR.txt                   Version: NSSDC 11/15/2001 JFC
-------------------------------------------------------------------------

This directory holds interplanetary solar wind plasma data from the 
Voyager 1 Plasma Science (PLS) experiment, which is briefly described in 
the file VY1PLA_NMC.txt extracted from the NSSDC Master Catalog. 

Subdirectories  Description
--------------  -----------

HOUR            Hourly averaged solar wind parameters for 1977 - 1980
                (later data have not been archived due to an instrument
                problem). See the file VY1PLA_1H_NMC.txt, extracted from 
                information in the NSSDC Master Catalog, for a overview 
                of  the data set. The file VY1PLA_1H_FMT.txt gives a brief 
                format description.

HIRES           High resolution solar wind parameters for 1977 - 1980. 
                The file VY1PLA_HIRES_FMT.txt gives a brief format 
                description.

SEDR            Spacecraft ephemeris data in heliocentric coordinates
                from the Voyager Supplementary Experiment Data Record 
                (SEDR) files generated by the Voyager project at the Jet 
                Propulsion Laboratory. Date coverage is from the 1977 
                launch to the year 2029 (well beyond the expected end of 
                the mission). The file VY1PLA_SEDR_FMT.txt gives a brief 
                format description. 


Related Information and Data:

Further details on the spacecraft, experiment, data sets at NSSDC, and 
related WWW sites can be found on the Voyager 1/2 flight project page 
under

http://nssdc.gsfc.nasa.gov/space/

Hour averages of the interplanetary solar wind data from, and hourly 
heliocentric coordinates of, Voyager 1/2 and other interplanetary spacecraft 
may be also be accessed and plotted on-line through the COHOWeb service 
based at the same WWW site as above.
