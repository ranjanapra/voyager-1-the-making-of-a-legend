### Challenge 02: RTG Nuclear & Thermocouple Power Curve (`challenge-rtg`)

### Challenge 03: Tsiolkovsky Rocket Delta-V for Hydrazine Thrusters (`challenge-deltav`)
- **Objective:** Calculate velocity change ($\Delta v$) in meters per second generated by firing the MR-102 catalytic hydrazine thruster clusters.
- **Physics Formula:**
  $$\Delta v = I_{sp} \cdot g_0 \cdot \ln\left(\frac{m_0}{m_f}\right) \quad \text{where } I_{sp} = 230.0\text{ s}, \; g_0 = 9.80665\text{ m/s}^2$$
