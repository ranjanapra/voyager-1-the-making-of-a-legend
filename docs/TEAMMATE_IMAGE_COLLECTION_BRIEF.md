## 1. PURPOSE & OBJECTIVES

This brief guides research teammates and digital asset specialists in collecting, verifying, and preparing authentic high-resolution NASA historical imagery to supplement or replace existing archival assets.

### Sourcing Directives
- **Allowed Sources:** NASA Photojournal (`photojournal.jpl.nasa.gov`), NASA Images (`images.nasa.gov`), NASA Planetary Data System (PDS), NASA Technical Reports Server (NTRS), NASA History Division (`history.nasa.gov`), and JPL SAF Archives.
- **Strictly Prohibited:** AI-generated images masquerading as historical photos, non-NASA promotional renders, generic stock photography (Unsplash, Shutterstock, Getty), fan art, or uncredited social media re-uploads.
- **Integrity Requirement:** Voyager 1 is an active, ongoing interstellar mission. Do NOT source or label images implying the spacecraft is "abandoned", "lost", or "discarded".

## 4. ASSET SUBMISSION CHECKLIST

When delivering collected assets to the project repository:
1. Save raw downloads to a staging folder or directly into `public/assets/images/research/`.
2. Ensure filenames are web-safe (lowercase, hyphens instead of spaces, no special characters).
3. Record exact NASA catalog ID (e.g. `PIA21734`), originating facility (JPL, KSC, GSFC), and archive URL in `docs/FINAL_IMAGE_INVENTORY.csv`.
4. Run image optimization (`npm run build` or WebP conversion) to ensure file sizes remain under 1.5 MB for rapid web loading.
5. Notify the engineering team to map the asset into `src/config/assets.js` and `src/scripts/story/explore-data.js`.
